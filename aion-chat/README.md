# AionsHome · AI 伴侣小家

AionsHome 是一个运行在自己电脑上的 AI 伴侣小家。你可以和两位伴侣分别私聊，也可以三个人一起生活。比如在群里说“冰箱里还有番茄和两个鸡蛋”，让两位各提一份晚餐；饭后接着读昨天那一章，看他们各自留的批注，再点开一位专门为这本书写的小曲。

每位伴侣有自己的名字、人设、声音、记忆和闲暇安排。小家由一台 Windows 电脑提供服务，电脑浏览器、手机浏览器和 Android App 共用聊天记录。聊天、记忆和作品主要保存在服务电脑上，使用云端模型、语音或生图时，相应内容会发送给所选服务商。

## 第一次启动

1. 将完整项目解压到纯英文路径。安装 64 位 Python 3.11，勾选 `Add Python to PATH`。
2. 双击项目根目录的 `一键安装环境.bat`。脚本会创建虚拟环境，优先使用 `vendor/` 里的依赖包，缺包时再联网安装。
3. 双击同一目录的 `一键启动.bat`，在电脑上打开 `http://localhost:8080`。手机连同一 Wi-Fi，将地址中的 `localhost` 换成电脑的局域网 IPv4 地址（可用 `ipconfig` 查看）。
4. 在首页「设置」填入自己的 Gemini 或硅基流动 API Key，或添加一条 OpenAI 兼容线路。回到「聊天」选择对应模型，发出第一条消息。已经配置好本机 Codex CLI 或 Antigravity CLI 的用户也可使用对应线路。

称呼和人设从「世界书」开始，第二位伴侣在「聊天室」配置。「工具与能力」里可以为角色开启想用的功能。[完整部署教程](../给朋友的部署教程.md)

## 查代码与旧记录

核心服务使用 Python、FastAPI 和 SQLite。浏览器与 Android WebView 共用前端页面，通过 WebSocket 同步消息。要定位某个功能，先读上表对应的说明；要找页面 URL、后端文件、模型配置或备份位置，见[服务结构与开发入口](docs/development.md)。
