        WELCOME TO THE GREEN ROOM

        瞄准，然后松手。

        一局定胜负，打完即可收杆；想再玩就从大厅开新的一局。默认休闲八球：不用报球报袋，先清完本组，再打黑八。

        1. 放白球拖到合法位置，再点确认。犯规后按提示重新放球。
        2. 拖动瞄准在白球的球杆一侧拖动，瞄准线朝向另一侧，手指不会挡住路线。抬手不会击球。
        3. 按住蓄力力度从 0 升到 100，再回落，循环往返。松手出杆；滑出按钮取消。
        4. 打自己的球合法进本组球就继续。先清完本组才能打八；犯规与自由球保留。

        RULES & SIMULATION

        球桌认真，操作轻松。

        休闲八球不要求指定球或袋。开放球桌由最先合法入袋的全色/花色球分组；同时入袋按球号确定。合法打进本组球可继续；只误进对方球留袋并换人。必须先清完本组，再合法打进黑八；提前进八或进八时犯规会输。

        严格模式保留报球报袋。两种模式均保留合法首碰、洗袋、无碰球、碰球后无进球也无碰库的犯规、自由球和开球处理选择。休闲模式是基于 WPA 的简化玩法。

        二维碰撞与摩擦近似；没有旋转、跟进/后退、弧线、跳球、真实飞出台面或推杆/触球技术犯规。没有比球，僵局直接重摆。瞄准线仅供参考。蓄力往返是本游戏的自定义操作。
