# 小厨房与家庭生活

## 今天吃什么

1. 打开「小厨房 → 冰箱清单」。按冷藏、冷冻、常温记下食材，余量可以写“半盒”或“两根”。一次采购可以点「批量记一笔」。
2. 在「我的口味」填用餐人数、做饭时间、喜欢的做法和忌口。开启「厨房 AI」后，可以在聊天里告诉伴侣刚买了什么、用掉了多少；有歧义的记录留在「待确认」里处理。
3. 请两位伴侣各提一份菜单。比如午餐选一位的番茄炒蛋，晚餐选另一位的汤，逐餐确认到同一张「今日餐桌」。菜单卡能展开做法，也可以单独换一餐。
4. 想再做前几天吃过的菜，到餐桌翻近七天的菜单。聊天里的菜单卡和小厨房显示的是同一份提案。

在聊天里问“冰箱还有什么”，能看到伴侣查看库存的提示。你报告的食材变动保存后，原消息旁会出现「小厨房已更新」，点它能回到小厨房核对。收到当天的菜单提案时也可以直接在聊天卡片选午餐或晚餐，再回「今日餐桌」看最后定下的搭配。

## 家里留下来的记录

| 入口 | 可以做什么 |
| --- | --- |
| 朋友圈、日记本 | 三个人可以发动态、配图、点赞和接着评论。日记本收自己的手写日记，也收 AI 整理的日记。 |
| 家庭动态 | 按时间回看家里的活动；走进两位伴侣各自的私人空间，可以翻旅行带回的照片、感想和线索。 |
| 许愿池 | 投下一个愿望，捞起后告诉某位伴侣或发到群里，做到了再标记完成。 |
| 爱的印记、钱包 | 在礼物陈列里重看伴侣送过的东西。聊天中的转账和牌桌结算使用小家里的虚拟钱包。 |
| 奥罗斯财团 | 记录基金持仓、查看行情和盈亏，让 AI 根据持仓做分析播报。 |

**转账、收礼和还愿都能从聊天或桌面开始。** 输入框「＋ → 转账」选金额，聊天室还可选收款的伴侣。确认金额后会放入输入框，可以再写句话，点发送才会发出；侧栏「钱包」可查余额和往来记录。回到小家桌面遇到礼盒时，点开盒子、点礼物看留言，然后「收下礼物」。许愿池里选「去实现」并告诉伴侣后，回到聊天卡片即可点「已完成」或「放回池中」。

**家庭动态的私人空间**可以记录纪念日；小旅行带回的卡片可以翻看照片和旅行线索，已经在聊天里聊过的卡片可标为「已提及」。
