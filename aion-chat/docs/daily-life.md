# 小厨房与家庭生活

## 每日作息

打开「日程监督 → 日程表」查看当天安排。每周作息和临时日程共用一张时间轴，显示添加者和提醒状态。左侧细线和圆点串起各个时段，当前时段会高亮；上方可选择日期、切换星期或翻到前后周。

点「编辑每周」后，周一到周日都可以分别编辑，每周自动循环。「复制到其他天」方便复用一天的安排，复制后仍各自独立。初次使用默认为空白安排，需要导入个人模板时可放在本地未跟踪的 `aion-chat/data/default_routine.json`；之后删除或清空不会重新填回。

点时段可编辑或删除，右上角「＋」可新增。编辑框的「修改范围」明确区分每周重复和只改当天；当天的临时调整可以用「恢复这天的每周安排」清除。在具体日期勾选「到点主动提醒」才会设置该次闹铃，每周计划本身不会自动生成闹铃。删除安排时会取消它关联的待触发提醒。

原来的日程监督照旧完整同步所有待执行的提醒、日程和监督，包含双方添加的记录及操作编号。双方仍可互相查看、撤销和新建，未来日期的提醒也会正常带上。

标题右侧的「共享作息」只控制新增默认作息的同步：在原有日程上下文后追加当前安排和两小时内的下一项。关闭后仍可在页面查看编辑默认作息，原来的日程监督照常工作。

原有「提醒管理」、历史和「快捷备忘」保留。两位伴侣给同一项安排设置同一时刻、同一种提醒时，会复用待触发记录；修改提醒沿用原编号，不额外创建。提前提醒时间和事情开始时间分开保存，旧记录没有事情开始时间时标为「提醒时点」。

## 今天吃什么

1. 打开「小厨房 → 冰箱清单」。按冷藏、冷冻、常温记下食材，余量可以写“半盒”或“两根”。一次采购可以点「批量记一笔」。
2. 在「我的口味」填用餐人数、做饭时间、喜欢的做法和忌口。开启「厨房 AI」后，可以在聊天里告诉伴侣刚买了什么、用掉了多少；有歧义的记录留在「待确认」里处理。
3. 请两位伴侣各提一份菜单。比如午餐选一位的番茄炒蛋，晚餐选另一位的汤，逐餐确认到同一张「今日餐桌」。菜单卡能展开做法，也可以单独换一餐。
4. 想再做前几天吃过的菜，到餐桌翻近七天的菜单。聊天里的菜单卡和小厨房显示的是同一份提案。

在聊天里问“冰箱还有什么”，能看到伴侣查看库存的提示。你报告的食材变动保存后，原消息旁会出现「小厨房已更新」，点它能回到小厨房核对。收到当天的菜单提案时也可以直接在聊天卡片选午餐或晚餐，再回「今日餐桌」看最后定下的搭配。

## 家里留下来的记录

| 入口 | 可以做什么 |
| --- | --- |
| 朋友圈、日记本 | 三个人可以发动态、配图、点赞和接着评论。日记本收自己的手写日记，也收 AI 整理的日记。 |
| 家庭动态 | 按时间回看家里的活动；聊天上下文范围内的动态会以「🏠」提示按时间出现在聊天里，伴侣也能读到；走进两位伴侣各自的私人空间，可以翻旅行带回的照片、感想和线索。 |
| 许愿池 | 投下一个愿望，捞起后告诉某位伴侣或发到群里，做到了再标记完成。 |
| 爱的印记、钱包 | 在礼物陈列里重看伴侣送过的东西。聊天中的转账和牌桌结算使用小家里的虚拟钱包。 |
| 奥罗斯财团 | 记录基金持仓、查看行情和盈亏，让 AI 根据持仓做分析播报。 |

**转账、收礼和还愿都能从聊天或桌面开始。** 输入框「＋ → 转账」选金额，聊天室还可选收款的伴侣。确认金额后会放入输入框，可以再写句话，点发送才会发出；侧栏「钱包」可查余额和往来记录。回到小家桌面遇到礼盒时，点开盒子、点礼物看留言，然后「收下礼物」。许愿池里选「去实现」并告诉伴侣后，回到聊天卡片即可点「已完成」或「放回池中」。

**家庭动态的私人空间**可以记录纪念日；小旅行带回的卡片可以翻看照片和旅行线索，已经在聊天里聊过的卡片可标为「已提及」。

健康记录、手环、摄像头以及应用监管见[手机与设备](devices.md)。生活照片与歌单见[阅读与创作](reading-creation.md)。
