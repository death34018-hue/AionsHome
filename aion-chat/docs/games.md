# 娱乐室与小游戏

从首页打开「娱乐室」选一张桌。也可以在日常聊天里约伴侣玩，收到邀请后直接点卡片入场。

| 玩法 | 一局怎样玩 |
| --- | --- |
| 台球室 | 选一位伴侣打休闲八球，拖动瞄准、蓄力击球。桌边支持文字和语音聊天，未打完的球桌可以暂停续玩。 |
| 斗地主 | 用户和两位伴侣各拿一手牌，叫地主、轮流出牌，打完可以直接再来一局。 |
| 吹牛骰子 | 两人或三人各摇一杯，你可以把叫数往上加，也可以质疑上家的叫数，开骰见分晓。 |
| 德州扑克 | 两人或三人入桌，看公共牌、跟注、加注或弃牌。牌桌使用虚拟筹码。骰子和德州完整打完一场并收桌后，群聊里会收到汇总战报；中途重开保留已完成的输赢，未完成的本轮作废。 |
| 聊天猜拳 | 在日常聊天里就能约一局。双方出拳后揭晓，结果留在原对话里。 |
| 奥罗斯幽林 | AI 担任主持人，玩家创建角色、掷骰、探索、获取和使用道具。不同冒险各自存档，下次选择原会话继续。 |

## 在聊天里猜拳或约一桌

点输入框「＋ → 猜拳」，先写本局约定，比如“谁输了谁挑今晚的电影”。群聊可以选要邀的那一位。选好拳型先放进输入框，还可以附一句话；点发送才发出邀请。伴侣也能主动约你，双方的拳型在揭晓前保密，最后的约定和输赢一起留在聊天里。

收到台球、斗地主、吹牛骰子或德州邀请时，点聊天卡片的「进入游戏」就能赴约。想让两位伴侣闲下来自己约球，在「家庭动态」给相应角色开启台球自主行动。

## 牌桌以外

- **Seeky** 是娱乐室里的小鲸鱼。可以喂食、照顾、互动，也可以在它自己的聊天窗口里和它说话。
- **爱的抱抱** 是拍拍抱枕的红外遥控器。有红外发射器的兼容手机对准抱枕即可使用。
- **去外面逛逛** 可以连接外部 MCP 服务。选择服务器、查看可用工具、写下想让伴侣探索的事，页面会显示行动过程和记录。

娱乐室大厅的服务入口是 `/playground`，外部 MCP 探索入口是 `/playground/explore`。
