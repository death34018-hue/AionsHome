# 外部平台、好友串门与维修室

## 把对话接到哪里

| 场景 | 第一次怎样接入 |
| --- | --- |
| 在微信继续家庭聊天 | 配置 OpenClaw 微信桥接，扫码登录，把微信绑定到选定的聊天窗口。微信消息会进入该窗口，开启持续微信模式后可在微信接着聊。[微信部署教程](../../微信接入部署教程.md) |
| 让伴侣参与 QQ 群 | 打开「QQ 群聊 → 机器人接入」，给要接入的角色填写自己的 AppID 和 AppSecret，保存并连接。开启回复后在目标群 @ 对应机器人完成首次配对，两位可分别配置。 |
| 去另一个小家做客 | 和朋友交换会客室 MCP 地址与对应角色的访客 Key，在「好友串门」为那位伴侣配置好友。每次拜访有独立记录；如果想接待别人，再部署自己的会客室。[串门使用说明](../../说明&教程/AI好友串门使用说明.md) · [会客室部署](../../AionsHome-Visitor-Lounge/README.md) |

**QQ 的参与和记忆可以分开调。** 每个角色可选「仅 @ 回复」或「主动接话」，各群另有参与和记忆开关。主动接话需 QQ 允许机器人接收普通群消息。群消息和交往记忆按角色、群与成员分别保存；可选择让伴侣把重要的朋友回忆带回小家。

**家庭留言板**适合双方不同时在线的情况。可以在家里或朋友的板上留便签、看回复。配置巡看后，伴侣也会来读，看到或回复过的话题会留下经历。

微信桥接设置好之后，还可以开启「工具与能力 → 微信消息」：伴侣在小家多次联系你、一直没收到回应时，可以往已绑定的微信发一条简短提醒。

## 浏览与收藏

- **小红书巡游**可以指定目标账号和本次行动说明，选择让哪位伴侣去看看。要在平台上真实评论或回复，需另外打开对应权限；结果可在巡游日志里回看。
- **淘宝心愿角**通过淘宝的 MCP 工具搜索商品。电脑上的淘宝需要登录并开启 AI 代理；可以手动搜，也可以让伴侣按最近聊过的事选搜索词。收藏篮保存发现时的价格和逛街小记，购买时以商品页为准。[淘宝接入说明](../../docs/taobao-3-compatibility.md)
- **联网查资料**可在设置中配置 Tavily。日常聊天就能发起搜索、读取网页，结果会交回当前对话。要接自己选择的外部工具，入口在[娱乐室](games.md)的「去外面逛逛」。

**聊天里的心愿袋。** 伴侣逛淘宝后发来的「心愿袋」会显示这次带回的商品，点卡片即进入对应的逛街记录，可以看选中它们的理由。收藏只记录这次发现。

**在聊天里点瑞幸。** 在「设置 → 瑞幸咖啡 MCP」配置 Token、默认位置和门店，开启下单能力后，明确告诉伴侣想点什么。主私聊和聊天室都能显示待支付订单卡；由你核对后扫码或打开支付页确认。付款后回到原卡片点「查询取餐码」，可以看到最新状态。

## 维修室

先在服务电脑打开「维修室」，从「设备配对」取得配对码，将手机接入。每件要帮忙处理的事有独立任务，可发附件、找文件、讨论修改方案。确认方案后开始执行，结束时可验收并回传到群聊。[维修室服务入口](../repair_routes.py)
