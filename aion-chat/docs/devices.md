# 手机、电脑与家里的设备

## 浏览器与 Android App

日常聊天、读书和写作可以直接用浏览器。电脑访问 `http://localhost:8080`，手机连同一 Wi-Fi 后使用电脑的局域网地址。配置 Tailscale 后可以从外面连回来。[多端同步说明](../../说明&教程/局域网多端同步方案.md)

Android App 增加了后台推送、原生拍照录像、悬浮聊天和桌面小组件。收到通知回到聊天页时，App 先读本机保存的消息事件，再与服务端校准。语音分段使用媒体缓存，已经缓存的片段可以直接重听。

- **本机语音转写**用于主聊天和聊天室。按住说话时，手机本地流式识别中英文；发送时仍会上传录音供回听。每台手机可以在「设置 → 语音转文字」单独切回云端。通话和唤醒沿用各自的语音配置。
- **自己编译 Android 客户端**时，在 `AionApp/` 下先运行 `python scripts/prepare-local-asr.py` 准备模型与运行库，再运行 `.\gradlew.bat assembleDebug`。首次准备需要联网下载模型。[Android 工程](../../AionApp/)
- **归巢模式**用于暂时连不上服务电脑的情况。手机要事先准备好灾备快照和可用云端线路，才能在手机上继续私聊或群聊；重新连回家后，可在归巢页面查看并回传这段时间的数据。
- **PC 桌宠与壁纸**可以通过项目根目录的 `启动桌宠.bat` 和 `启动壁纸.bat` 打开。壁纸支持在独立显示器上轮播媒体、显示聊天气泡。

### 离开 App 也能用

- **悬浮聊天。** 在 Android 的小家设置中开启「悬浮聊天」，授予悬浮窗和麦克风权限。离开 App 后可拖动小头像；点头像看消息，点正文展开最近对话，也可以从浮窗按住录音回复最近活跃的聊天窗口。
- **桌面小组件。** 伴侣可以切换自己在手机桌面小组件上的状态，或留一句横幅。小组件的快捷备忘与 App 同步，适合记只给自己看的事；备忘内容不会自动带进伴侣的聊天上下文。
- **小家自己的桌面。** 点时钟切换日夜主题，左右滑动翻页，长按应用图标可拖动调整位置。若希望聊天中的伴侣能让电脑上的桌宠做动作，先启动桌宠，再开启「工具与能力 → 桌宠动作」。
- **手机媒体缓存。** 在「设置 → 手机媒体缓存」可调整语音、图片和视频的缓存上限，或手动清理。超过上限时会先清理最久没用到的媒体，聊天记录仍可查看。

## 摄像头、定位与监管

| 入口 | 设备与用法 |
| --- | --- |
| 监控摄像头、监控日志 | 可接电脑摄像头、ESP32-CAM，或通过 Android App 使用手机摄像头。可以在聊天里请伴侣看一眼，也可以按时段巡查。哨兵先判断画面，必要时才交给聊天模型回应。 |
| 定位追踪、活动日志 | 配置高德定位后可以查看手机上报的位置。活动日志可看电脑前台窗口、手机应用活动，方便回顾一段时间做了什么。 |
| 监管 | 在 Android 授予相应权限后，可以按应用组设置计时、检查点、整机专注和临时解锁。计时、锁定和诊断保存在对应手机上。 |

## 健康与互动设备

- **健康和小米手环 7。** 健康页可记录体重、经期和步数。连接手环时，先填自己的绑定密钥，再扫描并选择设备。连接后能查看心率、活动和睡眠记录，也能让手环振动呼唤。[手环接入教程](../../说明&教程/小米手环七接入自有前后端教程.txt)
- **智能家居。** 通过 Home Assistant 配置希望伴侣控制的设备别名，就能在聊天里请它关灯或开插座。[智能家居接入教程](../../朋友接入智能家居教程.md)
- **互动设备。** 「密语时刻」提供兼容蓝牙设备的连接、预设与手动控制。「娱乐室 → 爱的抱抱」使用兼容手机的红外发射器控制拍拍抱枕。

**在聊天里叫手环、看附近、控设备。** 开启「手环呼唤」并连好手环后，伴侣可发一张显示在手腕上的小纸条，也可以轻震一次或连震三次。健康页的「给AI」决定聊天能否带上近期健康摘要。位置追踪开启且处于户外时，伴侣还可以按类别找附近地点。查看近期设备活动，则要同时打开工具能力和活动日志页的 AI 联动。

**密语设备按型号选。** SOSEXY 在密语模式里使用预设档位；ANKNI MX 支持把内置模式按时长编成一段；SVAKOM SL278H 支持循环编排和分项调节。后两种设备页都有「允许 AI 控制」开关。拍拍抱枕另有「工具与能力 → 拍拍抱枕控制」，可让伴侣发起拍打、调快或调慢。
