# 阅读、小说与创作

## 和伴侣读同一本书

把 EPUB 上传到「陪伴阅读」，打开一章，点「邀请共读」。两位伴侣各自留下批注和读后感。选中一句话，可以高亮、单独问一位，也可以带到群里讨论。下次翻到这里，能接着看当时的问答。点朗读可以听正文，也能听写下批注的那位亲自念给你听。

## 把小剧场写成一本书

「小剧场」可以选人设演一段戏，也可以开小说模式。先讨论人物和大纲，再逐章写正文、续写、修改和配插画。

- 点「本章已写完」确认正文，即可在剧场里邀请共读。「加入陪伴阅读」可将已经完成的章节一起放到书架，两个入口共用批注和划线。
- 重写已发布的一章，再次确认后会更新书架上的正文，并清理**这一章**旧版本的批注和划线。其它章节有各自的阅读进度。
- 「导出小说」默认只带走已完成章节。Word 会把插画放在正文中对应的位置，TXT 只带走文字。要连草稿也带走，可以勾选包含未完成正文。[小说模式与导出细节](../../docs/theater-novel-context.md)
- 章节里的「开始朗读」可以合成本章语音，之后点「收听本章」重听。正文旁的故事插画可以点开查看和保存，失败的配图可单独重试。

## 约会与学习角

「去约会」里可以选人设、给场景提示，生成大纲后互动推进剧情。结束时会得到摘要，由你选择要同步到哪段私聊或群聊。

「学习角」把当天的相处写成三幕英语对话。可以选由谁来写、取多少当天的素材，边看卡片边听朗读。练熟的一幕可移入「已学会」。

## 画一张图，留下一首歌

| 想留下什么 | 从哪里做 |
| --- | --- |
| 自拍或画作 | 在聊天里请伴侣画画，设置里可选择 Gemini、自定义生图接口、Codex 或 FlowAI 等线路。参考图可以用来保持角色形象。生成结果自动进「相册」，也可以上传自己的照片、分相册、收藏。放入家庭相册的照片可供已开启相应自主行动的伴侣翻看。 |
| 点过的歌 | 聊天里点歌，在「点歌台」找回。也可以上传本地音乐、建歌单、看同步歌词，或设置只播放喜欢的那一段。 |
| 一首有歌声的原创歌曲 | 配好歌曲生成服务后，在聊天里说明题材、风格和想唱的内容。Lyria 生成音频，歌曲文件保存在 `data/songs/`。 |
| 一段原创器乐 | 在「工具与能力」打开「作曲 · 小音乐盒」，试着说“给我写段尼龙弦吉他，晚上读书时听”。聊天卡片可直接播放、展开动态谱面。两位伴侣写的谱子由浏览器内的 Strudel 演奏，在「小音乐盒」按作者回听、收藏。 |

阅读的服务端入口在[书架与批注路由](../routes/book.py)。剧场、相册、点歌台和音乐盒的页面入口可在[主服务](../main.py)按名称查找。

## 聊天里的照片

- **查看一组图。** 同条消息的多张图片会叠在一起，点「展开」看整组。点缩略图看原图，左右切换同组图片，双指缩放或双击放大查看细节。
- **保存到哪里。** 长按聊天图片可选「保存图片」「查看大图」或「添加到相册」。「保存图片」用于下载到设备；「添加到相册」会复制一份到小家相册，原图仍留在聊天里。打开相册后还能批量移动分类，或将照片放进供伴侣翻看的家庭相册。
- **让同一个人在不同场景里长得一致。** 进「设置 → 管理人物锚点」，为人物填名字、别名、固定外貌和参考照，必要时绑定聊天身份。私聊、群聊和剧场共用这套人物；小剧场还能在创作设置里选择本故事的出场人物。
- **只重试失败的图。** 聊天室的生图失败卡片若显示「重试」，可以在原处重试这次生图，无需重新生成整段聊天回复。
