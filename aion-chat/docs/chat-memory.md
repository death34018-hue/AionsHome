# 聊天与记忆

## 从哪一个窗口开始

「聊天」是主伴侣的私聊。「聊天室」里可以和第二位伴侣单聊，也可以开一个三人的房间。称呼和人设在「世界书」与聊天室的人设设置里维护。群聊里的两位伴侣各用自己的模型和声音，回复会标出说话的人。

可以发文字、图片和带转写的语音气泡，也可以拍照、录视频给伴侣看。AI 回复逐步显示，日常聊天支持重新生成。电脑和手机看的是同一段对话。只记得一句原话时，在首页点「搜索聊天记录」，一次查群聊和两边私聊。

## 聊天窗口里可以点哪里

| 入口 | 能做什么 |
| --- | --- |
| 双击消息旁的头像 | 打开「拍拍」，可以改动作和后半句话，先看预览再发。可以拍伴侣，也可以拍自己。开启「工具与能力 → AI 拍拍」后，伴侣也可以主动拍你，群聊里还能拍另一位。 |
| 消息旁的 `⋯` | 普通消息可编辑、删除，AI 回复还能重新生成。**改自己的旧消息并确认，会从那里重新对话，后续消息会被移除。** 编辑 AI 回复则是修改那一条正文。回复还在生成时，输入框旁的 ■ 可以停止本轮。 |
| 主私聊的 `⋯ → ⭐ 星标` | 把值得留的话标出来。打开侧栏「星标消息」，点一条即可跳回原对话和原位置。主私聊的消息菜单也能复制正文。 |
| AI 回复旁的 👍 / 👎 | 可以写下具体喜欢或不喜欢哪里。主伴侣在「世界书 → AI 自动进化」、第二位在「聊天室 → 人设」能开启自动复盘，或点「立即复盘」「查看记录」了解这次改了什么。两位分别使用自己的点评与记忆。 |
| 回复旁的小图标 | 🔊 重听这条回复；有 💡 时可点开看这次写入记忆库的内容。模型返回了思考记录时才会出现 💭。另有「工具与能力 → 内心旁白」，开启后，角色偶尔会在正文旁写一句“心里嘀咕”。 |
| 侧栏的 📁 或「系统日志」 | 主私聊的 📁 可打开自动生成的聊天文本，编辑后点「保存并同步」会改回对应对话。两个聊天窗口都有系统日志，可查某次调用的模型、用量、提示词或错误详情，也可复制单条全文。 |

**输入框旁的「＋」** 可以多选图片或视频、拍照、发语音、打语音电话、猜拳和转账。「视频通话」在主私聊的菜单，「密语时刻」在聊天室菜单，也可从侧栏进入。语音消息按住说、松开发送，上滑取消。想把聊天里的图片留下，见[长按保存和入册](reading-creation.md#聊天里的照片)。

在电脑上可以直接把截图粘贴到输入框，从预览里移除不想发的附件。Enter 换行，Ctrl+Enter 发送；聊天室也支持 Shift+Enter。分享网页时，聊天里可显示链接预览卡，开启联网搜索后还能请伴侣读链接里的内容。

**聊天右上角的齿轮** 可调字号。主私聊还可调模型、上下文条数、温度和最大回复长度。「亲密玩法」按当前对话或房间开启：点「开始本轮」抽取玩法，眼睛按钮可预览，也可以换一套；群聊里会分别显示两位是否已读取。蓝牙设备另在[密语时刻](devices.md#健康与互动设备)选择和连接。

## 群聊里谁来说话

- **指定一位回答。** 房间设置的「群聊回复顺序」可选随机、谁优先或「指定回复」。选指定后，顶栏会出现两位各自的“说”按钮。想旁听两位自己聊，就点「让他们聊」，回合上限也在房间设置里。
- **各自的声音和上下文。** 房间设置可以给两位分别选模型线路、朗读音色，也能调跨窗口带入的上下文条数。主伴侣在「世界书」可预览注入内容；第二位的「人设」有可单独启用的补充设定。
- **群聊悄悄话。** 开启同名工具能力后，群里的一位伴侣可以把一句话单独送到你和它的私聊窗口，正文在那里读。
- **环境侦听。** 在群聊的房间设置里开启后，当前设备会侦听并转写，达到设置的字数或检查间隔时，由哨兵判断是否值得让某位伴侣插话。「侦听细项」可改唤醒词和结束词，也可查看、清空待检查片段。

## 伴侣什么时候会来找我

| 想做的事 | 用哪个入口 |
| --- | --- |
| 聊到一半去忙，希望过会儿有人再问一句 | 在「工具与能力」为对应角色开启「主动陪伴」。伴侣根据刚聊过的事决定要不要在接下来的 1～60 分钟内联系。 |
| 某天某个时间一定要提醒 | 在聊天里约好时间，或在「日程监督」查看和管理闹铃。由聊天创建的提醒会回到相应窗口。 |
| 想知道对方闲下来会做什么 | 打开「家庭动态」，两位伴侣各自有自主行动设置。旅行、翻家庭相册、约台球等能力可以分别开启。 |

输入框周围出现对应伴侣的流光，表示它已经安排了下一次主动联系。群聊能分别显示两位的状态，私聊只显示当前这位。

## 找回昨天、上个月的一件事

- **查原话**用首页搜索。**想让伴侣自己查**，可开启主动记忆搜索。回答时它可以按话题或日期找摘要，再打开来源看上下几句，也能查还没整理成记忆的聊天。
- **修改一条回忆**，进「记忆库」先选伴侣，再按日常、长期重要或朋友记忆筛选。打开「原文」可以核对出处，条目可以编辑或删除。
- **筛选记忆关联的原文**，在聊天室侧栏的「记忆库」打开条目的原文，勾选要保留的消息，再点「保存筛选」。这里也可以手动添加一条记忆，或用「总结记忆」整理当前积累的对话。
- **接住未完成的事**，从记忆库进「近期生活与待办」。页面显示实际会带进对话的近期清单，可以补记、改状态或结束当前活动。短期想法淡出后仍可去历史聊天找原话。
- **整理长时间积累的内容**，进「记忆压缩」。系统按日、周自动检查已经结束的周期，月整理可手动发起。压缩结果可以追溯到归档原文，主记忆库和聊天室记忆库分别处理。

## 语音与通话

语音消息保留录音和转写。普通消息可以用硅基流动、Edge TTS、MiniMax 或 ElevenLabs 的音色朗读。启用 ElevenLabs 主动语音后，伴侣还可以单独留一条带表演语气的语音，MP3 保存在 `data/voice_keepsakes/`。语音唤醒和半双工通话适合免手打字；视频电话可以把一段有声音的画面交给伴侣回应。

通话面板能在「免操作」和「按键发言」间切换，伴侣正在说话时可点「插话」。想先挑声音，可从主私聊齿轮点「试听音色」，试听 Edge 音色后点「加入候选」，再回聊天或小剧场选用。收到主动语音时，点气泡旁的「原文」还可以看这次交给语音服务的台词和语气提示。

手机本地转写、锁屏通知和后台回听见[手机与设备](devices.md)。需要定位聊天实现时，从[私聊路由](../routes/chat.py)、[聊天室路由](../routes/chatroom.py)或[上下文组装](../context_builder.py)开始。
